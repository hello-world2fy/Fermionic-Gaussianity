# 两体密度 Jastrow 的占据概率约束

本节给出独立于非凸局部拟合的排除判据。它适用于固定对数子空间中的

\[
 \psi(n)=d_{m(n)}\exp\!\left(\sum_{i<j}J_{ij}n_i n_j\right),
\]

其中每个 `d_m` 和 `J_ij` 都可为任意复数；线性占据项已被固定总对数的二次项包含。
它不适用于任意一般 projected Gaussian、任意 Gaussian 叠加、任意 Jastrow 混合，
也不构成量子相干的独立见证。下面的恒等式和上界是解析结果，归档中的数值代入为 float64，
没有为真实 Schrödinger 解提供区间认证。

## 1. 八个构型的恒等式

选取互不重叠的三对能级，其中两对跨越上下能带，第三对位于同一能带。
每对中恰有一个配对能级占据，其余能级占据固定。三个二元选择记作 `x,y,z`。
总粒子数始终固定，而转移数为 `m=m0+x+y`，与第三个带内选择 `z` 无关。

每个 `n_i` 是这三个变量的仿射函数，所以任意 `n_i n_j` 是至多二次的多线性函数。
任意径向项 `log |d_(m0+x+y)|²` 只依赖两个变量，三阶交替差分同样为零。因此

\[
 p_{000}p_{011}p_{101}p_{110}
 =p_{001}p_{010}p_{100}p_{111}.
\]

零概率情形通过连续极限成立。构型概率可理解为固定其他占据并要求每组选一个的事件；
它不是把其他能级求和后的六能级边缘概率。边缘化通常破坏此恒等式。
数据文件记录的是未条件化的全构型概率，使用时也可除以八个事件的总概率。

统计模型中这属于已知的无三因素相互作用约束，并非新的统计恒等式。
参见 Geiger、Meek、Sturmfels (2006), Example 2：
[On the toric algebra of graphical models](https://math.berkeley.edu/~bernd/AOS0092.pdf)。
这里的应用是选择保持总粒子数、并消去任意径向系数的配对占据交换。

计数条件轨道 `exp(sum_j z_j(m)n_j)` 则可违反恒等式：`z_j(m0+x+y)` 与第三个带内选择相乘，
其三阶项测量转移数与能级选择之间超出二体指数的耦合。
仅线性依赖 `m` 的轨道仍属于两体 Jastrow，因此恒等式仍成立。

## 2. 保真度上界

在一个八构型事件 C 内，令总概率为 P，归一化非负幅值
`a_v=sqrt(p_v/P)`，并定义

\[
 f(a)=\prod_{v\in E}a_v-\prod_{v\in O}a_v,
 \quad E=\{000,011,101,110\},\ O=\{001,010,100,111\}.
\]

在正单位球内，设两组幅值平方的总和分别为 `s_E,s_O`。Maclaurin 不等式给出

\[
 \|\nabla f\|^2=e_3(a_E^2)+e_3(a_O^2)
 \le(s_E^3+s_O^3)/16\le1/16.
\]

任何满足恒等式的归一化候选幅值 b 因而满足
`||a-b|| >= 4|f(a)|`。其局部经典亲和度平方至多为
`B_C=(1-8 f(a)²)²`。量子重叠绝对值不超过幅值的经典亲和度。
再优化候选态在 C 中的未知总概率，Cauchy–Schwarz 不等式给出

\[
 F(\psi,\phi)\le 1-P(1-B_C).
\]

若选择互不重叠的多个事件 C，则

\[
 \boxed{F(\psi,\phi)\le1-\sum_C P_C\,[16 f_C^2-64 f_C^4].}
\]

无需找到最好的事件集合即可得到有效上界。本实现按单事件贡献贪心选择不重叠事件，
没有宣称得到最紧上界。它甚至允许候选态拥有任意构型相位，故不会把相位拟合困难当成振幅排除证据。

## 3. 数值范围与解释

`L=12,G=2` 共枚举 108000 个合法事件。在 `t=2.15` 选出 87 个不重叠事件，
覆盖概率 0.695938，得到 `F <= 0.9994914373` 的浮点代入值。
局部多起点 Jastrow 拟合给出的可行下界约为 0.9721905356。
两者之间仍有明显空隙；不能声称最优误差就是 2.8%。

单个贡献最大的事件有总概率 0.0584837、`f=-0.0125611`。
该事件的两体 Jastrow 拟合值为浮点零，三次计数轨道和组合族分别约为 -0.008446、-0.008678。
这些事件根据精确脉冲态事后选择，因此这一诊断不是独立的预测成功。
目前没有完成实验采样量、噪声稳健性或热力学尺度分析，不据此宣称可直接实验发现的新效应。

实现见 `pairing_formation/density_cubes.py`，独立随机二次指数核查见 `tests/test_density_cubes.py`。
