# FK 模型：一套有可能产生新结果的数值实验方案

我建议把核心问题确定为：

> 当两个具有相互作用质量的 FK 团簇逐渐耦合时，最优 Gaussian decomposition 是否会发生从“局域质量构型”到“跨团簇纠缠构型”的转变？这种转变能否得到严格的必要性定理？

这个问题比单纯计算 Gaussian extent 更有价值，因为它试图把一个表示资源量与具体的多体物理结构联系起来。

我检查了 FK 的原始哈密顿量，并做了一次小规模精确对角化。发现这个实验有两个特别有利的性质：

1. 完整体系只有 8 个复费米模式，而且所选基态所在的对称子空间只有 3 维。 因此可以把目标波函数计算得非常准确。
2. 可以先证明一个 Gaussian 构型的局域质量与跨团簇关联之间的严格约束。 这使后续实验有明确的理论目标，而不只是画图寻找规律。

下面分成模型、解析结论、数值实验、潜在新发现四部分。

## 一、模型：两个耦合的 FK 团簇

示意图。团簇内通过四费米相互作用形成 FK 基态；团簇之间用二次 Majorana 耦合。虚线仅示意耦合，实际有八个 Majorana 通道。

设 \\(\gamma\_{x,a}\\) 是团簇 \\(x=A,B\\) 内的八个 Majorana 算符，满足

\\[ \\{\gamma\_{x,a},\gamma\_{y,b}\\} =2\delta\_{xy}\delta\_{ab}. \\]

定义七个局域质量算符

\\[ Q\_{x,\alpha} = \frac{i}{4}\gamma_x^{\mathsf T}J\_\alpha\gamma_x, \qquad \alpha=1,\ldots,7, \\]

其中 \\(J\_\alpha\\) 是实反对称的 \\(8\times8\\) Clifford 矩阵：

\\[ J\_\alpha J\_\beta+J\_\beta J\_\alpha =-2\delta\_{\alpha\beta}I. \\]

选择哈密顿量

\\[ \boxed{ H(t,V)= -V\sum\_{x=A,B}\sum\_{\alpha=1}^7Q\_{x,\alpha}^2 +\frac{it}{2}\sum\_{a=1}^8\gamma\_{A,a}\gamma\_{B,a}. } \tag{1} \\]

这与 You–He–Xu–Vishwanath 的 FK \\(SO(7)\\) 模型采用相同的相互作用结构，只是这里对 \\(V\\) 使用了方便数值计算的归一化。原文 Appendix C 可以作为实现依据。

物理上存在两个极限：

- \\(t=0\\)：两个独立的强相互作用团簇，基态为 \\(M_A\otimes M_B\\)，Gaussian extent 为 \\(4\\)。
- \\(t/V\rightarrow\infty\\)：跨团簇二次耦合占主导，基态趋于一个 Gaussian 态，Gaussian extent 趋于 \\(1\\)。

这里 extent 在 \\(t=0\\) 的乘法性有现成的文献支持。

### 一个已完成的计算：精确的三维哈密顿量

我使用显式 Majorana 矩阵对这个八模式模型进行检查，发现从 \\(M_A\otimes M_B\\) 出发，在团簇间耦合下生成的 Krylov 子空间恰好闭合在三维。

在适当的正交基底中：

\\[ \boxed{ H\_{\rm singlet}= \begin{pmatrix} -56V&\sqrt2t&0\\\ \sqrt2t&-14V&\sqrt{14}t\\\ 0&\sqrt{14}t&-8V \end{pmatrix}. } \tag{2} \\]

我检查了这个子空间在局域相互作用和跨团簇耦合下都严格封闭，并且与完整 \\(256\\) 维 Fock 空间的基态能量一致。

所以，对于这个模型，获得精确基态根本不是计算瓶颈。真正困难的是给定这个态，找到它在完整八模式 Gaussian 流形上的最优连续表示。

这为实验提供了特别干净的基准。

## 二、我得到一个更有意思的解析结果：Gaussian 平均场会出现一个虚假的临界点

先不运行你们的连续分解算法，而是考虑传统的 Gaussian 变分近似：

\\[ E_G(t,V)=\min\_{g\in\mathcal G_8} \langle g|H(t,V)|g\rangle. \\]

也就是问：如果强制整个八模式体系始终由单个 Gaussian 态描述，会得到什么？

在当前 \\(SO(7)\\) 对称模型里，可以把这个优化解析完成。

### 1. 定义两类相互竞争的结构

对任意全局纯 Gaussian 态 \\(g\\)，把它的 Majorana covariance 写成

\\[ \Gamma_g= \begin{pmatrix} A&C\\\ -C^{\mathsf T}&B \end{pmatrix}. \\]

其中 \\(A,B\\) 是两个团簇内部的协方差，\\(C\\) 是跨团簇协方差。

定义跨团簇关联强度

\\[ \boxed{\eta(g)=\frac{\\|C\\|\_F^2}{8}} \\]

和局域质量向量

\\[ \boxed{ m\_{x,\alpha}(g)=\frac12\langle g|Q\_{x,\alpha}|g\rangle. } \\]

对全局纯 Gaussian 态，\\(\Gamma_g^2=-I\\)。因此

\\[ \\|A\\|\_F^2+\\|C\\|\_F^2=8. \\]

再利用 Clifford 矩阵的正交关系和 Bessel 不等式，可以严格推出

\\[ \boxed{ \\|\mathbf m_A(g)\\|^2+\eta(g)\le1, \qquad \\|\mathbf m_B(g)\\|^2+\eta(g)\le1. } \tag{3} \\]

这个结论具有非常直观的意义：

单个纯 Gaussian 态不能同时拥有饱和的局域 FK 质量，以及最大的跨团簇 Gaussian 纠缠。

两者在其协方差中竞争同一份资源。

### 2. Gaussian 基态能量可以精确优化

利用 Wick 定理和当前 FK 相互作用的 Clifford 结构，局域能量满足

\\[ \left\langle-\sum\_{\alpha}Q\_{A,\alpha}^2\right\rangle_g = -7+\frac38\\|A\\|\_F^2 -12\\|\mathbf m_A(g)\\|^2, \\]

对团簇 \\(B\\) 亦然。

结合式（3）和跨团簇 hopping 能量的 Cauchy–Schwarz 界，可以得到

\\[ \langle H\rangle_g \ge -32V+18V\eta(g)-4t\sqrt{\eta(g)}. \\]

而且这个界能够被一族具有局域质量方向的纯 Gaussian 协方差矩阵饱和。因此并非仅仅是能量下界，而是完整 Gaussian 流形上的精确最小值：

\\[ \boxed{ E_G(t,V)= \begin{cases} -32V-\dfrac{2t^2}{9V},&0\le t\le9V,\\\\[5pt] -14V-4t,&t\ge9V. \end{cases} } \tag{4} \\]

对应最优 Gaussian 构型的结构为

\\[ \boxed{ \begin{aligned} \eta_G^\*&=\min\left\\{\frac{t^2}{81V^2},1\right\\},\\\ \\|\mathbf m_A\\|^2 &=\\|\mathbf m_B\\|^2=1-\eta_G^\*. \end{aligned} } \tag{5} \\]

这意味着：

- \\(t/V<9\\)：最佳单 Gaussian 态具有非零局域质量方向，打破 \\(SO(7)\\) 对称性。
- \\(t/V=9\\)：局域质量连续消失。
- \\(t/V>9\\)：最佳单 Gaussian 态成为纯跨团簇配对的对称 Gaussian 态。

所以单 Gaussian 变分理论在

\\[ \boxed{t_c^{\mathrm{Gaussian}}=9V} \\]

出现一个临界结构：质量序参量消失，变分基态能量的二阶导数不连续。

但精确的两团簇基态在这一附近始终是对称的、非简并的，数值检查也没有发现能隙闭合。

因此，这给出了一个很明确的研究机会：单 Gaussian 平均场产生了一个实际上不存在的有限体系相变，而最优 Gaussian superposition 是否能够解释这个错误，并连续连接两侧的物理？

这比简单研究 extent 的数值变化更有物理针对性。

### 3. 精确对角化还发现了一个值得解释的关联峰

定义真正的四费米质量关联：

\\[ C_Q(t)= \sum\_{\alpha=1}^{7} \langle\psi(t)|Q\_{A,\alpha}Q\_{B,\alpha}|\psi(t)\rangle. \\]

再从精确态的二点协方差出发，按照 Wick 定理构造相应预测 \\(C_Q^{\mathrm{Wick}}(t)\\)。

在本模型的对称性下，

\\[ C_Q^{\mathrm{Wick}}(t)=-7\eta\_\psi(t), \\]

其中 \\(\eta\_\psi\\) 是精确态的跨团簇二点协方差平方强度，而非 Gaussian 分解中 \\(\eta(g)\\) 的平均。

因此可以定义真实的四点关联偏差

\\[ \boxed{ \mathcal W(t) = C_Q(t)+7\eta\_\psi(t). } \tag{6} \\]

这个量为零，意味着该组四点关联可以由二点协方差的 Wick 分解解释；非零则检测到超出 Wick 分解的关联。

我已经用上述三维精确哈密顿量计算了它：

数值上，\\(|\mathcal W|\\) 的最大值约为

\\[ \boxed{ t/V\simeq10.92,\qquad |\mathcal W|\_{\max}\simeq5.02. } \\]

它恰好位于 Gaussian 变分临界点 \\(t/V=9\\) 的附近。

这个峰本身还不能算新的物理发现；它只是一个有限模型中的可精确计算结果，而且我没有证明文献中尚未出现过类似观察。

但是它提供了一个很具体、可否定的研究目标：

最优连续 Gaussian 分解能否解释为什么真实的四费米关联在平均场质量消失附近仍然很强，并且呈现非单调增强？

这里要特别避免误解：将每个 Gaussian 成分当成经典随机质量构型，直接平均其 Wick 关联，一般不能重构 \\(\mathcal W\\)。必须保留不同 Gaussian 成分之间的相干矩阵元。

## 三、真正值得研究的对象：最优分解中的“质量—纠缠转换”

上面的平均场结果已经可以独立成立。但你们的工作需要进一步回答：

精确基态能否通过最低成本的 Gaussian 构型组合，同时保留强四点关联、恢复 \\(SO(7)\\) 对称性，并消除平均场的虚假临界点？

我建议先研究两种相互竞争的 Gaussian dictionary。

| Dictionary                                     | 允许的 Gaussian 构型          | 物理意义                    |
| ---------------------------------------------- | ------------------------ | ----------------------- |
| 完整字典 \\(\mathcal G_8\\)                        | 允许任意跨团簇协方差               | 真正的 Gaussian extent     |
| 乘积字典 \\(\mathcal G_4^A\otimes\mathcal G_4^B\\) | 每个 Gaussian 成分必须是两个团簇的乘积 | 只依靠局域 Gaussian 构型进行相干叠加 |

定义两者的最小系数成本为 \\(\tau_G\\) 和 \\(\tau\_{\rm prod}\\)，均满足 \\(\xi=\tau^2\\)。

两个极限的结果是：

|                                       | \\(t=0\\) | \\(t/V\to\infty\\) |
| ------------------------------------- | --------- | ------------------ |
| 完整 Gaussian 成本 \\(\tau_G\\)           | 2         | 1                  |
| 乘积 Gaussian 成本 \\(\tau\_{\rm prod}\\) | 2         | 4                  |
| 团簇间纠缠熵（bits）                          | 0         | 4                  |

最后一行的极限态在 A、B 间具有 4 ebits 纠缠。乘积字典的成本 4 可由 Schmidt 系数给出下界，并由 16 个乘积 Fock 态的展开达到。

这里已经出现了很有意思的反差：

随着两个团簇耦合增强，真实态逐渐变得更 Gaussian，却同时变得更加跨团簇纠缠。

如果坚持用局域 Gaussian 成分表达，成本反而上升。

### 一个可以直接证明的“必要性定理”

令精确态具有分解

\\[ |\psi\rangle=B\int|\widetilde g\rangle\\,dP(g), \\]

其中 \\(P\\) 是归一化的正概率测度，\\(B\\) 为相干系数总质量。

定义目标态关于 A/B 分割的 Schmidt 核范数：

\\[ L(\psi)=\operatorname{Tr}\sqrt{\rho_A}. \\]

对于任意纯 Gaussian 成分 \\(g\\)，由其 Gaussian Schmidt normal form 可以证明

\\[ L(g)\le(1+\sqrt{\eta(g)})^2. \\]

而 Schmidt 核范数满足三角不等式。因此

\\[ L(\psi) \le B\\,\mathbb E_P L(g) \le B(1+\sqrt{\mathbb E_P\eta(g)})^2. \\]

从而得到：

\\[ \boxed{ \mathbb E_P\eta(g) \ge \left( \sqrt{\frac{L(\psi)}{B}}-1 \right)\_+^2. } \tag{7} \\]

这里 \\(x\_+=\max\\{x,0\\}\\)。

这是一个重要的区别：它不只适用于你们 canonical decomposition，而是适用于任何给定系数成本的精确 Gaussian 分解。

结合之前的 Gaussian 质量—纠缠互补关系，

\\[ \mathbb E_P\\|\mathbf m_A(g)\\|^2 \le1-\mathbb E_P\eta(g), \\]

便能限制近最优分解中局域质量的大小。

例如，精确对角化给出在 \\(t/V=20\\) 时

\\[ L(\psi)\simeq3.8853. \\]

如果后续算法找到了 \\(B\le1.2\\) 的精确分解，就必然有

\\[ \mathbb E_P\eta(g)\gtrsim0.638. \\]

也就是说，成本足够接近最优时，分解不可能主要依靠没有跨团簇关联的 Gaussian 构型。

注意这里的 \\(B\le1.2\\) 是一个待达到的实验目标，并非我已经计算出的结果。

这类定理才真正把 Gaussian extent 的最小化，与组成态的物理性质连接起来。

### 实验 B：运行你们的连续 Gaussian synthesis

你们现有算法已经足以定义这个计算。

对每个 \\(t/V\\)，求解

\\[ u_k(t)=\arg\min_u \left[ \frac{q_k(u)}{2k} -\operatorname{Re}\langle u|\psi(t)\rangle \right], \\]

然后得到

\\[ dP\_{k,t}(g) \propto |\langle g|u_k(t)\rangle|^{2k-1}d\mu(g). \\]

关键是利用三维对称子空间。

若 \\(\\{|s_0\rangle,|s_1\rangle,|s_2\rangle\\}\\) 为前面的正交基，由于目标态在对角 \\(\mathrm{Spin}(7)\\) 下不变，而且有限 \\(k\\) 的凸优化器唯一，因此

\\[ \boxed{ u_k=z_0|s_0\rangle+z_1|s_1\rangle+z_2|s_2\rangle. } \\]

不需要对一般的 128 维复向量做优化。

对 Haar Gaussian 样本 \\(g\\)，只须预先计算三个重叠：

\\[ h_j(g)=\langle g|s_j\rangle. \\]

之后目标函数变为

\\[ q_k(z) = d\_{8,k} \int \left|\sum\_{j=0}^2 z_j h_j(g)\right|^{2k} d\mu(g). \\]

可以先使用 \\(k=1,2,3,4,6,8\\)，再根据方差与数值条件决定是否提高。

这里仍需要从完整八模式 Gaussian 流形进行 Haar 采样，不能因为 witness 只有三维，就把 Gaussian 字典也错误地缩减为三维。

为了控制可靠性，应独立检查重构残差

\\[ \rho_k=\\|\psi-C_k(u_k)\\|, \\]

并比较不同采样量和 \\(k\\) 的结果。算法说明中的凸优化、归一化与独立验证步骤可以直接复用。

### 实验 C：画真正有意义的 Gaussian 分布

我不建议直接画七维质量方向的各分量分布。由于 \\(SO(7)\\) 对称性，它很容易只给出一个平凡的各向同性结果。

应当研究 \\(P\_{k,t}\\) 在以下不变量上的推前分布：

\\[ \boxed{ \left( \\|\mathbf m_A(g)\\|^2,\\, \\|\mathbf m_B(g)\\|^2,\\, \mathbf m_A(g)\cdot\mathbf m_B(g),\\, \eta(g) \right). } \\]

最关键的是局域质量与跨团簇关联的联合分布：

建议的二维分布图结构

坐标结构示意，不是实际模拟分布。纵轴从下到上表示局域质量平方；实际可允许的区域满足质量平方 + η ≤ 1。

真正值得检查的是：

当 \\(t/V\\) 从 5 经过 9 增加到 20 时，最优分解的质量是否沿着这条互补边界发生转移？

如果出现两个不同构型族的竞争，进一步研究接触集合、witness 峰值和相干贡献，就可能得到比资源量曲线更强的结果。

还应计算每个成分的 Gaussian 能量 \\(\langle g|H|g\rangle\\)，检查最优 extent 分解是否偏好接近 Gaussian 变分能量极小值的构型。两种优化目标不同，不能预先假设它们的最优 Gaussian 原子一致。

### 实验 D：证明哪些构型不能省掉

这一项我认为最有可能从数值工作发展为一个正式定理。

对于满足 \\(\eta(g)\le\eta_0\\) 的受限 Gaussian 字典，上述 Schmidt 范数不等式直接给出

\\[ \boxed{ \tau\_{\eta\le\eta_0}(\psi) \ge \frac{L(\psi)}{(1+\sqrt{\eta_0})^2}. } \tag{8} \\]

因此你们可以采用如下比较：

在 \\(t/V=20\\) 时，精确态有 \\(L\simeq3.8853\\)。如果限制每个 Gaussian 原子的跨团簇强度为 \\(\eta\le0.25\\)，那么任何精确分解都满足

\\[ \boxed{ B\_{\mathrm{restricted}}\ge \frac{3.8853}{(1+0.5)^2} \simeq1.727. } \\]

只要完整 Gaussian synthesis 找到并可靠验证 \\(B<1.727\\) 的分解，就证明了：

低跨团簇关联字典不可能实现当前已知的完整字典表示成本。

这里不需要依赖某张分布图的主观解释，而是存在严格的成本分离。

如果进一步建立对更一般相互作用模型也成立的类似判据，就有较明确的理论价值。

## 六、我对这个课题最终价值的判断

现在已经有一个比较完整的研究故事：

\\[ \boxed{ \begin{gathered} \text{FK 相互作用支持局域质量构型}\\\ \Downarrow\\\ \text{单 Gaussian 平均场产生虚假临界点}\\\ \Downarrow\\\ \text{精确基态保持对称且有强四费米关联}\\\ \Downarrow\\\ \text{最优 Gaussian decomposition 可能解释其相干组成}\\\ \Downarrow\\\ \text{成本约束给出组成态结构的必要性定理} \end{gathered} } \\]

我认为最有价值的不是再证明 FK 模型有能隙——这个早已知道——而是证明：

> 对称性恢复和跨团簇关联的形成，可以由一个成本最优的 Gaussian 相干展开来描述；而且相应的构型变化不是任选的表示方式，而是近最优性所强制的。

目前，三维精确约化、单 Gaussian 能量公式、互补不等式以及 Schmidt 成本约束已经提供了可用的理论起点。尚未完成、也不能提前宣称成立的是：canonical Gaussian 分布确实出现有意义的支持结构变化，以及这种变化能够定量解释 \\(\mathcal W(t)\\) 的峰。

我建议下一步优先算出 \\(\xi_G(t)\\)、\\(B_k(t)\\) 和质量—跨团簇联合分布。 如果这些结果能与前面的必要性界形成闭环，这个 FK 实验就不再只是对既有 Gaussian decomposition 算法的演示，而有机会成为一项独立的物理研究。
